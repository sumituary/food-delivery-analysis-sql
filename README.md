# food-delivery-analysis-sql
SQL project exploring a fictional food delivery database using SQL queries and analysis.

Food Delivery Analysis using SQL 

Project Overview

This project explores a fictional food delivery database using SQL. It focuses on analyzing customer orders, restaurant performance, menu items, payments, and delivery operations.

Database Structure

The database contains eight tables:

Customers

Restaurants

Menu Items

Delivery Partners

Orders

Order Items

Payments

Deliveries

The tables are connected using primary keys and foreign keys.

SQL Concepts Practiced

SELECT statements and filtering

JOINs

Aggregate functions

GROUP BY and ORDER BY

CASE statements

Common Table Expressions (CTEs)

Subqueries and LIMIT

Analysis Areas

Order details and customer information

Revenue and order values

Popular menu items

Orders by status

Revenue by cuisine and city

Peak ordering hours

Restaurant ratings

Payment methods

Top customers by spending

Restaurant order fulfillment

Dataset

The database uses fictional sample data generated with AI assistance for learning and practice. It does not represent real food delivery transactions or actual business performance.

Tools Used

MySQL

MySQL Workbench

How to Run

Download Food_Delivery_Analysis_SQL.sql from this repository.

Open MySQL Workbench and connect to your MySQL server.

Open the SQL file.

Review the script, then execute it to create and populate the database and run the analysis queries.

Note: Review the script before running it, especially if you already have a database with the same name.

What I Learned

This project gave me practice designing a relational database, connecting tables, writing SQL queries, and exploring data through analysis. AI assisted with brainstorming the database structure and generating sample data.
